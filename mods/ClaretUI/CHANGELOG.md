## Сборка 20261119-07 — 2026-11-19
- Секция открывалась пустой: дерево `root/list/detail` не было привязано к хосту и не имело `Depth`. У `root` оставались координаты `0,0` экрана и глубина по умолчанию, поэтому всё рисовалось под шеллом панели. Теперь `Relayout` ставит `root` в `parent` (`0,0`, размер хоста), глубины — `root = parent+1`, `list/detail = root+1` (как в embedded `KeyboardEditor`).
- Ширина применяется сразу через `ApplyWidth` (Core при создании редактора `OnResize` не вызывает): панель была бы верно 552, а контент оставался бы 504 до следующего `SetPanelSize`.
- Добавлена строка `[ClaretUI][section] built; groups=1 host=…` для проверки в логе.
- Панель КБ: убран помощник `Global` на `rawget(_G, …)` — движковые глобалы так не видны, из-за этого не работали перетаскивание (`drag is unavailable`), поиск КБ и звук тревоги. Теперь имена читаются напрямую в `pcall`; `Dragger` принимается как вызываемая таблица.

## Сборка 20261119-06 — 2026-11-19
- Почему 0.2.2 не помогла: строка `Create = Create` после `local function Create` — присваивание **локальной** переменной, а не глобальной. Правка ничего не меняла, `UiSection.Create` оставался пустым. Теперь фабрика объявлена как `function Create(...)` — так же, как `Build` в `BuildKeyLabels.lua`.
- `features/AcuHealth.lua`: `Start` теперь есть, но панель прерывалась с «Bitmap is unavailable» — проверка требовала `type(Bitmap) == 'function'`, а классы Maui (`ClassUI`) — вызываемые таблицы. Проверка принимает и таблицу.
- Раннер учитывает область видимости: присваивание имени, которое уже объявлено локально, экспортом не считается.

## Сборка 20261119-05 — 2026-11-19
- Настоящая причина пустой секции `UI`: `import` в FAF возвращает таблицу-окружение модуля, а не значение `return`. `UiSection.lua` и `features/AcuHealth.lua` объявляли API через `local` + `return`, поэтому вызывающий код получал пустую таблицу и падал с «nonexistent global variable Create / Start».
- Оба модуля экспортируют API глобалими модуля (как `Theme.lua` и `BuildKeyLabels.lua`); заодно убрано ложное утверждение сборки 04 о проверке в Fengari — там стаб `import` возвращал значение `return`, чего FAF не делает.
- Раннер дополнительно запрещает файл, который заканчивается `return` без единого экспорта-глобала.

## Сборка 20261119-04 — 2026-11-19

- Раннер тестов теперь запрещает любые varargs в ClaretUI по AST (правило против повторения).
