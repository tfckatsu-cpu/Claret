# Этап 1: актуальное состояние

Рабочие моды находятся в соседнем каталоге `mods/`. Git-зеркала синхронизируются после подтверждения в FAF. Claret остаётся клиентским UI-проектом.

## Claret UI

**Уведомления — Claret UI 0.2.101, сборка 20261120-104.** Из завершения эксперименталок исключены спутник Novax и Отуи; станция Novax и Итота остаются. Целевые тесты прошли, фильтр в FAF не проверялся. В 0.2.88 (20261120-91) пользователь подтвердил в FAF уведомление СМД и затем сборку с миниатюрой установки. Оба целевых теста прошли. Для сборки 0.2.87 прошли 74 локальных теста. Отдельного результата проверки эксперименталки или СМД без выделения пользователь не сообщил.

**Reveal Positions — Claret UI 0.2.80, сборка 20261120-83.** Пользователь сообщил, что предыдущие значки пересвечены. Введены однотонные цвета фракций: синий, зелёный, красный и жёлтый, без усиления яркости; внутренние линии прозрачны. Фон остаётся за текстом, без значка. Цвета и прозрачность текстур проверены локально; полный прогон: 72 теста прошли. Пользователь подтвердил в FAF: «сейчас всё работает хорошо»; отдельные сценарии и масштабы не перечислены. Оригинальный мод одновременно не включать.

**Selection Info — 0.2.73, сборка 20261120-76 / Core 0.10.27, сборка 20261120-59.** Название в F10 → Claret → UI одинаково в обеих локалях. Цифры используют яркие цвета общей темы, настройки отдельных показателей находятся в закрытом по умолчанию блоке «Дополнительно». Доступны динамический режим, подписи, блокировка, прозрачность и масштаб 50–200%. HUD перетаскивается ЛКМ и сохраняет позицию отдельно от масштаба. Локально прошёл 71 тест. Пользователь подтвердил результат словами «Всё хорошо», без перечисления игровых сценариев. Коммит `e5e3c87` опубликован в `origin/dev`.

**0.2.66, сборка 20261120-69.** Переключатель меток управляет цифровой меткой и заливкой, переключатель индикатора — стрелкой. Ранее сохранённые положения переключателей сохранены. Проверены четыре комбинации без перезапуска локального сценария. Три целевых теста прошли; проверка в FAF ожидается.

**0.2.64, сборка 20261120-67.** Раздел мини-карты переименован в Better Minimap в обеих локалях. В ACU Health добавлен сохраняемый переключатель блокировки положения. Три целевых теста прошли, ввод в FAF ожидает проверки.

**Mex Overhaul — Claret UI 0.2.63, сборка 20261120-66.** Пользователь подтвердил итоговую сборку в FAF и запросил коммит. Журнал подтвердил версию сборки. В предыдущих проверках подтверждена адаптивная панель: без мексов скрыта, при появлении T1 показывает три ячейки. Пользователь подтвердил финальную правку выравнивания значка паузы. Отдельный результат перезапуска с сохранённой позицией не сообщён. Полный локальный прогон: 71 тест прошёл.

Панель поддерживает статичный режим из семи ячеек и адаптивный режим по уровням, ручные действия с апгрейдом, ввод через меню клавиш FAF, перетаскивание ЛКМ, сохранение и блокировку положения, масштаб 50–200% и прозрачность единого фона 0–100%. Жёлтая стрелка и необязательная цифровая метка видны на карте. Источник поведения — EUT v11. Три DDS мексов из Redux ACU Icons атрибутированы macdeffy; разрешение на использование с указанием автора задокументировано. Золотую стрелку предоставил пользователь.
**Подтверждено в FAF ранее:** All Rings 0.2.38, оформление навигации и ползунка 0.2.32, мини-карта UI 0.2.33 / Core 0.10.25, включая вручную закрытую карту.

All Rings по умолчанию выключен. В F10 → Claret → UI → All Rings Shift/Ctrl задаются отдельно для атаки и строительства, клавиша атаки общая для наведения и выделения. Alt показывает радиус реклейма выбранного инженера или завода. Дополнительные фильтры и мини-карта в свёрнутом блоке.

ACU Health показывает HP, регенерацию и заряд щита. Масштаб 50–200% сохраняется в профиле. Тревога срабатывает ниже 15% и 5%, снимается при 17% и 7%. После гибели полосы исчезают, затем надпись и фрагменты панели затухают. Пользователь подтвердил действие эффекта гибели для 0.2.19, его обновлённая анимация и крайние случаи ожидают проверки.

**InfoShare — Claret UI 0.2.100, сборка 20261120-103.** Добавлены иконки с подложкой в HUD и значки апгрейдов БМК, названия взяты из уведомлений. Режимы показа, блокировка с пропуском мыши и ползунки в основном списке, фильтры и значки в «Дополнительно». Работы автоматически передаются союзникам при включённом Claret UI, независимо от HUD. Координаты работ также передаются автоматически. Ползунки применяются через OnChanged, подписи при масштабировании сохраняют контролы. После повторного появления пустых плашек HUD создаёт только строки с работами и удаляет лишние при сокращении списка. Заливка прогресса не зависит от прозрачности фона. Итоги видны 1,5 секунды перед затуханием. Пользователь в целом подтвердил результат 20.11.2026 и запросил коммит. Отдельных результатов проверки обмена с союзниками и пропуска мыши не сообщил.
