# Этап 1: актуальное состояние

Рабочие моды находятся в соседнем каталоге `mods/`. Git-зеркала синхронизируются после подтверждения в FAF. Claret остаётся клиентским UI-проектом.

## Claret UI

**Selection Info — 0.2.73, сборка 20261120-76 / Core 0.10.27, сборка 20261120-59.** Название в F10 → Claret → UI одинаково в обеих локалях. Цифры используют яркие цвета общей темы, настройки отдельных показателей находятся в закрытом по умолчанию блоке «Дополнительно». На основной странице доступны показ HUD, динамический режим, подписи, блокировка, прозрачность и масштаб 50–200%. HUD перетаскивается ЛКМ и сохраняет позицию отдельно от масштаба. Локально проверены обе локали, настройка полей, снятие выделения, восстановление сводки Core и очистка подписок. Пользователь разрешил коммит. В FAF проверить читаемость с прозрачным фоном, ввод, масштаб и применимость показателей к реальным юнитам.

**Mex Overhaul — Claret UI 0.2.63, сборка 20261120-66.** Пользователь подтвердил итоговую сборку в FAF и запросил коммит. Журнал подтвердил версию сборки. В предыдущих проверках подтверждена адаптивная панель: без мексов скрыта, при появлении T1 показывает три ячейки. Пользователь подтвердил финальную правку выравнивания значка паузы. Отдельный результат перезапуска с сохранённой позицией не сообщён. Полный локальный прогон: 71 тест прошёл.

Панель поддерживает статичный режим из семи ячеек и адаптивный режим по уровням, ручные действия с апгрейдом, ввод через меню клавиш FAF, перетаскивание ЛКМ, сохранение и блокировку положения, масштаб 50–200% и прозрачность единого фона 0–100%. Жёлтая стрелка и необязательная цифровая метка видны на карте. Источник поведения — EUT v11. Три DDS мексов из Redux ACU Icons атрибутированы macdeffy; разрешение на использование с указанием автора задокументировано. Золотую стрелку предоставил пользователь.
**Подтверждено в FAF ранее:** All Rings 0.2.38, оформление навигации и ползунка 0.2.32, мини-карта UI 0.2.33 / Core 0.10.25, включая вручную закрытую карту.

All Rings по умолчанию выключен. В F10 → Claret → UI → All Rings Shift/Ctrl задаются отдельно для атаки и строительства, клавиша атаки общая для наведения и выделения. Alt показывает радиус реклейма выбранного инженера или завода. Дополнительные фильтры и мини-карта в свёрнутом блоке.

ACU Health показывает HP, регенерацию и заряд щита. Масштаб 50–200% сохраняется в профиле. Тревога срабатывает ниже 15% и 5%, снимается при 17% и 7%. После гибели полосы исчезают, затем надпись и фрагменты панели затухают. Пользователь подтвердил действие эффекта гибели для 0.2.19, его обновлённая анимация и крайние случаи ожидают проверки.
