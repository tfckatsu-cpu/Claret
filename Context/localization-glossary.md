# Глоссарий Claret EN/RU

| Term (EN) | Русский вариант | Правило |
| --- | --- | --- |
| ACU | ACU | Сокращение; не склонять и не переводить. |
| SACU | SACU | Сокращение; не склонять и не переводить. |
| Hotbuild | Hotbuild | Название функции и мода; сохранять написание. |
| extractor | экстрактор | В игровых названиях брать текст из blueprint/LOC; для кратких UI-ярлыков допустимо «мекс». |
| unit | юнит | Для краткого UI-текста; имена юнитов всегда брать из игры. |
| blueprint | чертёж юнита | Только в документации; в интерфейсе обычно не показывать. |
| order | приказ | Использовать для игровых приказов. Их названия брать из описаний FAF. |
| action | действие | Для действия Hotbuild/Claret, которое может вызвать приказ или выбор. |
| selection | выделение | `empty selection` → «пустое выделение». |
| binding | бинд | Для пользовательского назначения. Не переводить как «связь». |
| key assignment | назначение клавиши | Предпочитать в пояснениях; краткая подпись «бинд» допустима. |
| multifunction binding | мультифункциональный бинд | Полное название функции; не смешивать с обычным назначением клавиши. |
| preset | пресет | Профиль построек Hotbuild. Пользовательское имя не переводить. |
| build template | шаблон строительства | Имя, заданное пользователем, сохранять дословно. |
| context | контекст | Тип текущего выделения в редакторе мультифункциональных биндов. |
| builder | строитель | Контекст инженера/командира, используемый Hotbuild. |
| factory | завод | Контекст и игровая постройка; конкретное имя здания брать из игры. |
| mex | мекс | Краткий игровой жаргон для экстрактора; в документации писать «экстрактор». |
| T1 / T2 / T3 / T4 | T1 / T2 / T3 / T4 | Оставлять латинское обозначение уровня. |
| obsolete assignment | устаревшее назначение | Для сохранённой ссылки, которую нельзя назначить заново. |
| chain-occupied | занято цепочкой | Для контекста, зарезервированного продолжением действия. |
| fallback action | резервное действие | Не переводить как игровой приказ. |
| quick repeat | быстрый повтор | Механика повторного нажатия Hotbuild. |

Имена юнитов и штатных приказов не переводить вручную: использовать игровые blueprint-описания через `LOC` и штатные описания действий FAF. В таблицы вручную включать только строки интерфейса Claret. Логи оставлять на английском.
